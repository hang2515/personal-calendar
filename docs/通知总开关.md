# 通知总开关（0.4.1）

## 使用方式

在“我的 → 通知与提醒”关闭“接收提醒通知”，即可停止本机所有日历提醒，并清除已显示的提醒通知。各日历的提醒开关、时间、计划和打卡保持不变；重新开启后恢复后续计划，不补发已过时间的提醒。

“打开通知设置”在开启与关闭状态下都可使用，用于调整 Android 系统通知权限、声音和显示方式。应用总开关与系统授权分别保存；应用不能自行撤销或授予系统权限。总开关开启但系统权限未允许时，页面继续提供授权入口。

## 实现与兼容

- 本机 SharedPreferences 保存总开关，旧版本升级默认开启，不改变既有日历行为。该偏好不进入云备份，不改变 Room 表结构或云快照协议。
- 保存关闭状态后取消各日历闹钟并清除通知；实际发送与取消操作共用互斥锁，防止在途接收器在关闭完成后重新通知。
- 编辑日历、重启、权限变化和恢复后的调度均检查总开关。保存后的取消或重排使用不可取消的有限操作，避免离开设置页时只完成一半。
- 开启不代表已获得系统授权；准时闹钟、省电限制、勿扰模式和厂商通知设置仍由系统控制。

## 验证范围

回归覆盖关闭后取消闹钟/通知、重新创建调度器后保持关闭、在途提醒不发送、重新开启安排下一次计划、保留各日历配置，以及系统未授权时不安排提醒。界面覆盖关闭、返回后状态持久化、重新开启及系统通知设置入口。
