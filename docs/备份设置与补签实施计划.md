# 备份设置与补签 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 清晰分开云上传和读取，支持每日定时备份与历史计划日补签。

**Architecture:** 复用 Room、备份协调器和 Compose。每日任务由 WorkManager 管理，时间仅保存本机偏好；补签复用 check_ins 唯一键与历史规则校验。

**Tech Stack:** Kotlin、Compose Material 3、Room、WorkManager、AppAuth。

**Spec:** [备份设置与补签设计](备份设置与补签设计.md)

## Global Constraints

- 北京时间 `Asia/Shanghai`，本地功能无需登录，保持云接口/快照/数据库兼容。
- 每日 00:00–23:59 可选；断网和系统省电可能延后。
- 补签仅创建日起截至昨天的历史计划日；未来和未安排日期拒绝。
- 上传/恢复仍需账号、版本和 ETag 校验及用户确认。

## Review Focus

次日生效排期、暂停期间、重复请求、换账号覆盖、恢复后自动备份状态、运行中修改时间/关闭备份、后台失败后的下一天任务。
