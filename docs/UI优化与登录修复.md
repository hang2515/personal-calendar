# 0.3.0 界面优化与登录修复

## 目标与实现顺序

1. 用回归测试复现浏览器登录请求失败，修复 AppAuth 参数使用及错误提示。
2. 保持暖白、鼠尾草绿视觉，统一标题、留白、白色卡片与主次操作。
3. “我的”首页只展示账号、简洁备份摘要和设置列表；备份操作进入管理面板，保留预览、覆盖与恢复确认。
4. 新建入口融入日历页标题；完成状态与小尺寸撤销入口同排，详情管理操作收进菜单。
5. 提醒时间使用小时、分钟双列滚轮，24 小时制；取消不修改，确认后应用。
6. 验证登录参数、滚轮选择与取消、无登录设置入口、创建/打卡/撤销/删除；完整构建与 Lint 后交付新 APK。

## 边界

继续本地优先、不强制登录、北京时间、当天打卡与整份云备份。数据库和云接口保持兼容。本轮不部署 AWS，不增加 UI 库。

## 设备验收

本地测试无法替代真实浏览器与 Cognito 回跳。需要在手机验证登录/注册、取消授权、授权返回，以及滚轮手势、大字体和窄屏。

## 登录问题根因

旧实现把 `prompt=login` 传入 AppAuth 的 `setAdditionalParameters`。`prompt` 是其内置参数，SDK 会立即抛出 `IllegalArgumentException`，此时还未调用浏览器。旧界面把所有启动异常显示为“请确认已安装浏览器”，因此误导了排查。

改用 `setPrompt(AuthorizationRequest.Prompt.LOGIN)`，保留授权码、PKCE、nonce、state 和原有 scope。测试先复现参数异常，再验证修复后的请求地址与安全参数。真实缺少可用浏览器与登录请求构建失败现在使用不同提示。合并后的 Manifest 已包含 AppAuth 的 HTTPS 浏览器查询，无需重复添加权限。

## 界面行为

- “我的”：账号概览、紧凑备份摘要、设置分组；较窄屏幕或大字体时，备份按钮自动放到摘要下方。
- 云备份管理：预览与恢复、立即备份、关闭自动备份、账号安全和退出继续保留。预览与最终确认不再叠加显示。
- 今天及详情：完成状态与“撤销”在同一行，保持 48dp 触控区域与“撤销打卡”无障碍说明。
- 日历：标题旁的圆形“＋”新建；详情菜单管理编辑、暂停及删除。删除仍需确认。
- 时间：滚轮停下自动吸附，选择范围为 00:00–23:59；取消不修改，确认才应用。大字自动增加行高，矮屏可滚动到确认按钮。
- 配色、标题层级、白色卡片和导航统一；颜色选择项支持窄屏换行。

原生渲染截图由 `UiPreviewTest` 生成到 `app/build/ui-preview/`，是测试环境实际 Compose 画面，示例数据不来自用户记录。
