# 云备份实施记录

目标：保留本机无需登录的日历、打卡和提醒，新增可选账号、完整云备份和换机恢复。

## 实施顺序

1. 本地数据库 4→5：状态表、业务版本、快照校验、原子恢复及测试。
2. AWS CDK：Cognito、HTTP API、Lambda、私有版本化 S3、监控和预算。
3. 安卓：AppAuth PKCE、Keystore 令牌存储、WorkManager、云备份界面。
4. 部署测试环境并验证鉴权、隔离、版本冲突；部署生产环境，构建 APK。

## 约定

- 在用户指定的当前工作区及现有功能分支继续，保留现有项目和测试。
- 应用与数据使用香港区域 ap-east-1，预算堆栈使用 us-east-1；AWS CLI 配置 my-aws，凭据不进入仓库。
- 完整 JSON 快照最大 1 MiB；格式版本独立于 Room 版本；不做多设备自动合并。
- 恢复和账号重新绑定需应用内明确确认，退出登录保留本地数据。
- 状态表及业务更新同事务；云端使用 ETag 条件写入。
- 云端费用预算提醒 5 美元/月，不代表硬性消费上限。
