# 0.3.1 图标与全界面复查

## 交付范围

重新设计启动图标，逐页复查此前 UI 优化和登录修复，补齐发现的问题，构建可覆盖安装的调试 APK，并将代码与 APK 版本附件上传私人 GitHub 仓库。

## 图标

采用深绿色底、暖白日历页和简洁打卡勾，保持小尺寸识别度。使用 Android 原生矢量前景及独立背景，由启动器决定圆形或圆角外轮廓；Android 13+ 提供单色层以支持主题图标。

![Android 实际渲染的启动图标](branding/launcher-icon.png)

源文件位于 `app/src/main/res/drawable/ic_launcher_foreground.xml`、`ic_launcher_monochrome.xml` 和 `mipmap-anydpi-v26/`、`mipmap-anydpi-v33/`。采用可编辑矢量资源，不引入位图生成依赖。设计依据：[Android 自适应图标](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)。

上一版已调整六个主要页面、主题和导航，但截图覆盖偏向普通尺寸，尚有返回行为和大字体边界遗漏。本轮逐一检查以下范围：

| 页面 / 组件 | 复查重点 |
| --- | --- |
| 今天 | 日期、进度、未完成/已完成、撤销、空数据和失败提示 |
| 日历列表 | 新建入口、日历切换、月历预览、月份导航、日期状态和详情入口 |
| 日历详情 | 月份、进度、日期格、打卡、管理菜单、编辑/暂停/恢复/删除确认 |

## 登录验证的边界

此前 `prompt` 内置参数误用已修复；本轮继续验证。开发机访问生产 Cognito 授权地址返回 HTTP 200，并检测到密码输入框和注册入口。该检查未输入账号密码，不代表真实用户授权回跳、注册邮件或大陆不同运营商网络已验收。

原生应用可独立使用；未改变数据库、云接口和备份协议，也没有部署新的 AWS 服务。

## 本轮补齐的问题

- 系统返回按新建、编辑、详情的页面层级返回，不直接退出应用。
- 通知跳转消费后清除原 Intent 参数，切换底栏不会再次打开旧通知；新的通知仍能进入目标日历。
- 通知权限拒绝后保留系统设置入口，并处理找不到系统设置页面的失败提示。
- 月份导航提供明确的上月/下月无障碍说明，窄屏大字体下保留按钮和年份。
- 日期格随字体增大高度，完成与未完成状态采用矢量符号，避免字体符号溢出。
- 星期选项及提醒时间支持换行，提醒开关保留空间，弹窗使用与页面一致的暖白配色。

截图由真实 Compose 组件和 Android 原生渲染生成，覆盖今天、完成状态、日历列表、详情、新建、编辑、我的、时间滚轮、通知弹窗和窄屏大字体月历。生成位置为忽略的 `app/build/ui-preview/`，并非真机截图。
